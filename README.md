# Passport Toolkit

A lightweight, browser-based passport utility toolkit built with HTML, CSS, and JavaScript by **Tasfiq Ahmed**.

### Features
- **MRZ Generator:** Generate ICAO TD3 passport MRZ lines with automatic check digits.
- **DOB Formatter:** Convert dates into standard or MRZ formats.
- **Text Case Tools:** Sentence, lowercase, uppercase, capitalized, and title case.
- **Passport ID Generator:** Generate random A-prefixed reference IDs.
- **AI Image Prompt Generator:** Create realistic passport-style photo prompts.
- **Dark / Light Mode:** Switch themes with saved preferences.
- **Export & Copy:** Copy generated data and download MRZ as PNG.

### Getting Started
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start using the tools. No installation required.

### Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage API
- Canvas API
